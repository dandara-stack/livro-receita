# Livro de Receitas

Aplicação para cadastrar e organizar suas receitas favoritas.

## Funcionalidades

Página inicial de apresentação. Cadastro de novas receitas na página Minhas Receitas.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript.

## Como executar

Clone este repositório e abra o arquivo index.html no navegador.
